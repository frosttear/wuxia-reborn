## 游戏概述

每世角色从 **15 岁**开始，每月推进一次，触发随机事件，通过选择获取属性与奖励，磨砺武艺、结交人物。**20岁生辰**，天魔如约而至——无论强弱，这场决战无可回避。失败后双鱼玉佩触发**世界线回溯**——时间倒流，你带着这一世的记忆回到起点的另一条世界线，在新的时间线中变得更强。

参考：虚拟人生（Virtual Life）——以时间流逝代替掷骰走格，每次选择都有重量。

```
无名小卒
  └─→ 游侠  (力量 ≥ 12)
        └─→ 剑客  (力量 ≥ 18, 敏捷 ≥ 12)
              └─→ 剑侠  (力量 ≥ 26, 敏捷 ≥ 15, 声望 ≥ 18 + 武林认可任务)
                    └─→ 剑宗  (力量 ≥ 36, 内力 ≥ 18, 敏捷 ≥ 20, 声望 ≥ 25 + 剑意传承任务)

**任务门槛**：剑侠需完成「侠名之路」任务链（`hero_recognized` flag，首节「义救灾民」需达到**剑豪**职业）；剑宗需完成「剑道传承」任务链（`sword_legacy` flag）。高阶职业通过专属任务线解锁，包含剧情、属性门槛和战斗考验。

## 战斗系统（回合制）

### 基础数值公式

```
攻击力 = floor(力量) + 职业基础攻击 + 技能加成 + 被动加成
防御力 = floor(体质×0.4 + 敏捷×0.6) + 职业基础防御 + 技能加成

闪避率 = 运气/120 + 敏捷/250（上限 25%）
会心率 = 运气/120（上限 35%）
气盾   = floor(内力/8) + 天赋/被动加成（每次受击扁平减伤）
技能增幅 = max(0, (我方内力 - 敌方内力) / (双方内力之和 + 10) × 40%)
```

### 伤害公式（Bravely Default 式比例减伤）

```
baseDmg = floor(ATK² / (ATK + DEF + 1))
```

防御属性为比例减伤而非固定减法——高防御大幅减伤但永不为零，彻底消除「攻防相近时输出 1 点」的问题。双向对称，玩家与敌人使用同一公式。

**强攻伤害**：
```
dmg = max(1, floor(baseDmg × lv × (1 + 内力增幅)) - 敌方气盾)
```
- `lv`：运气浮动系数 `1 ± (luck/200)`
- 会心一击 ×1.5

**反击伤害**（破招成功时）：
```
counterDmg = max(1, floor(baseDmg × counterMult) - 敌方气盾)
```
- 普通反击 `counterMult = 0.75`，洞察反击 `counterMult = 1.0`
- 技能就绪时以技能代替基础反击（含多段/震慑等特效）

**防御减伤**（随攻防比缩放）：
```
powerRatio = min(1, 防御力 / max(1, 敌方攻击力))
defCap = min(0.75, powerRatio × 0.75 + 0.10)
```
- 防御 vs 重攻：减伤 min(75%, defCap)
- 防御 vs 快攻：减伤 min(50%, defCap)
- 蓄势减伤：min(55%, defCap)
- 洞察快攻时防御减伤突破 defCap：至少 defCap+15%（上限80%）

### 行动选项

| 行动 | 效果 | 气力 | 备注 |
|------|------|------|------|
| ⚔ 强攻 | 造成伤害，可暴击（×1.5） | +2 | BD比例减伤，永不为零 |
| 🛡 防御 | 重攻减伤75%，快攻减伤50% | — | 识破快攻时减伤提升至80% |
| ⚡ 破招 | 克制重攻：反击+仅承受20%伤害 | +1 | 破招失败：×1.15伤害 |
| 🔮 蓄势 | 减伤55%，积攒气力 | +3 | 用于蓄满技能槽 |
| 🏃 逃跑 | 25%成功率，每次失败+15% | — | 失败时受全额伤害 |

- **技能**：气力满后下回合自动发动（强攻/蓄势时触发），冷却3回合
- **破招反击**时若技能就绪，以技能作为反击招式发动（含多段连击等），不浪费技能

### 敌方行为

敌人每回合随机选择**重攻**或**快攻**：
- 气血 > 35% 时：重攻概率 45%
- 气血 ≤ 35% 时：重攻概率 65%（孤注一掷）
- ⚠️ 敌人没有「破招」行动

### 敌方意图识别

每回合结束时，根据悟性判断是否能识破敌人下回合出招意图：

```
识破概率 = min(50%, 80% × ln(1 + 悟性 / (敌方悟性 + 20)))
```

| 识破结果 | 显示 |
|---------|------|
| 识破（accurate） | 真实意图描述，100% 准确 |
| 看不清（unreadable） | 模糊迷惑文字 |
| 无相剑意被动 | 永远 100% 识破（perfect） |

**意图应对加成**（仅在 accurate/perfect 时生效）：

| 识破结果 | 应对行动 | 加成效果 |
|---------|---------|---------|
| 快攻来袭 | 防御 | 减伤提升至 80%（普通防御快攻仅50%） |
| 重攻来袭 | 破招 | 反击倍率提升至 1.0×（普通 0.75×），额外+1气力 |

### 职业主动技能

每个职业拥有一个主动技能，战斗面板**全程显示**技能名称、效果及剩余所需气力：

| 状态 | 显示 |
|------|------|
| 蓄势中 | 「技能名」效果描述　还差 X 气 |
| 可发动 | ⚡「技能名」蓄势完成，下回合自动发动！（金色闪烁） |
| 冷却中 | 「技能名」效果描述　冷却中（剩 X 回合） |

### 战斗预览系统

点击战斗动作按钮后展开预览栏，显示预估伤害/减伤/气力变化等详细数值；再次点击同一按钮执行行动。默认选中强攻。

### 其他机制

- **快速战斗**：胜率接近100%时可一键跳过，蒙特卡洛50局模拟直接结算
- **战斗状态持久化**：战斗进行中刷新页面不丢失状态（localStorage）
- **受伤状态**：战斗失败后进入重伤，强制参与「养伤」事件共 **3个月**，第4个月自动痊愈。王铁被动可将恢复期缩至 2 个月
- **敌人属性缩放**：敌人攻防HP随角色年龄动态成长（`tier = 年龄 - 15`）

**每月气血回复**（百分比制）：
- 基础：15% 最大 HP
- 体质：每点 +0.5% 最大 HP（20体质 = +10%）
- 内力：每点 +0.5% 最大 HP（20内力 = +10%）
- 苏青被动「青心丹药」：额外回复 100% 损失气血（几乎一月回满）

## 世界线回溯系统

**设定**：双鱼玉佩在佩戴者濒死时触发时间倒流，将意识连同记忆送回另一条世界线的起点。这不是转世，而是世界线的分岔——你记得「未来」发生过的一切。

**触发条件**：被 Boss（天魔或剑魂）击败。普通战斗失败只会重伤，不触发回溯；游戏无寿命上限

**继承内容**：
1. **属性继承**：所有属性 × 10%（天赋可提升比例）
2. **出生月份**：同一命运，同一生辰
3. **世界线记忆**：上条世界线的羁绊等级 → 新世界线初始好感加成，且已结识NPC无需再次相识
4. **传承天赋**：本世成就解锁，每世选 **2** 个

## Boss 设计与结局系统

### 结局路径

```
天魔战（20岁生辰，无条件触发）
  → NPC 羁绊效果生效（见下方 NPC 效果表）
    → 剑魂（sword_soul）无条件现身

剑魂——两条路径：
  ├─ 容器路径（NPC 联结不足 / 无无相剑意被动）
  │     → 被吞噬 → 玉佩激活 → 世界线回溯
  │       （首次触发后，后续轮回解锁 NPC 分支线）
  └─ 精神完整路径（NPC 联结足够 / 具备无相剑意）
        → 胜 → 「碎片真相」任务链
                  → 揭露神秘老者即沈玄清
                    → 沈玄清（叙事强制战败——他主动为之，将主角送往九百年前）
                      → 九百年前：目击封印瞬间
                          → 以人间之力击败剑魂本源（jian_hun_origin）
                              └─ ✦ 真·天下太平 ✦（封印解除，沈玄清九百年牺牲终结）
```

### Boss：天魔（陆无归）
- **触发**：20岁生辰无条件降临，天魔本体数值较高，NPC 效果不足时难以胜出
- 凌雪羁绊第5章会预先触发一场隐藏Boss战（凌雪本人），作为额外关卡

### Boss：剑魂（当代）
- **触发**：击败天魔后**无条件**触发
- 上古剑修残留意志，九百年前被沈玄清以七成修为封印于双鱼玉牌；沈玄清用自己作为封印容器，以人间联结压制那道力量
- **精神完整路径**：具备足够 NPC 联结（或无相剑意），剑魂认出你不只是另一个容器，发出千年追问「力量为何而存」——战后剑魂在消散前第一次感到某种没有名字的东西
- **容器路径**：联结不足，剑魂判断你是容器，吞噬开始；玉佩激活，救出主角，触发世界线回溯
- **无相剑意**：六羁绊满级后可解锁的任务链，获得 `perfectIntentRead` 被动（洞察率100%），是精神完整路径的关键

### Boss：沈玄清（叙事强制战败）

- **性质**：叙事机制而非真正战力考验。他等了九百年，等的就是这一刻——找到够格的人，送他去九百年前。战败是他主动为之的最后一步

## 存档系统

- `localStorage` 自动存档（`wuxia_save`）
- 继续游戏时恢复最近 **30 条**事件日志（`wuxia_log`），显示「── 上次存档 ──」分隔线
- **导出/导入**：存档码（Base64）复制到剪贴板，可跨设备迁移或分享

## 技术架构

- **技术栈**：纯 HTML + CSS + JS，无框架，GitHub Pages 直接部署
- **数据层**：JSON 文件（jobs / npcs / events / enemies / bonds / chains）
- **存档**：localStorage 自动存档 + Base64 导出/导入
- **测试**：Jest 317 测试（角色/战斗/引擎/数据/HTML完整性/API表面），Husky pre-commit 钩子

```

  npc.js            NPC好感度与关系系统
  combat.js         回合制战斗

  engine.js         游戏主引擎（月度推进、生日系统、事件触发、真结局）
