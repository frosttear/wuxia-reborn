# MyPages

A collection of static HTML pages hosted on GitHub Pages.

🌐 **Live Site**: [https://frosttear.github.io/MyPages/](https://frosttear.github.io/MyPages/)

## Pages

| Page | Description |
|------|-------------|
| **[弹药防线 (Ammo Defense)](ammo-defense.html)** | Post-apocalyptic tower defense game with ammo logistics, weapon upgrades, and synergy system ([details](ammo-defense/README.md)) |
| **[游泳年卡打卡台账](swim-pass-checkin.html)** | A local-first static tracker for swim pass check-ins, people, and monthly usage counts |
| **[Music Generator](music-generator.html)** | Interactive music generator tool |
| **[Scratch Blocks Compiler](scratch-blocks-compiler.html)** | Deep dive into how Scratch blocks are compiled to JavaScript |

| **[Async/Await Thread Switching Pitfall](async-await-thread-pitfall.html)** | Interactive presentation about common async/await pitfalls |
| **[棒球 (Baseball)](Baseball.html)** | A baseball game built with Scratch & TurboWarp |

## Features

- **Index Page**: A modern navigator with card-based layout
- **Localization**: Supports Chinese (中文) and English, with Chinese as default
- **Responsive Design**: Works on desktop and mobile devices

## Usage

Simply visit the GitHub Pages URL or open `index.html` locally. Use the language switcher in the top-right corner to toggle between Chinese and English.
