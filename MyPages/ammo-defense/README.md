# 弹药防线

> 末日要塞风格塔防游戏 · 弹药物流 + 武器升级 + 共鸣系统 · 纯 Canvas 2D

---

## 游戏简介

在末日要塞的最后补给线上，你需要管理弹药生产、调度搬运工、为枪手和炮台持续装填，抵御一波又一波敌人的进攻。共 10 关，每关 10 波，通关后可进入无尽模式。

---

## 核心玩法

### 武器系统

| 武器 | 弹种 | 特点 |
|------|------|------|
| **枪手** | 子弹系（普通/穿甲/冰冻） | 射速快、单发伤害低，适合清理小怪 |
| **炮台** | 炮弹系（普通/燃烧/高爆） | 射速慢、单发伤害高，自带 AOE 范围爆炸 |
| **机枪**（改装枪手） | 子弹系 | 极速扫射，DPS 最高 |
| **狙击**（改装枪手） | 子弹系 | 高单发伤害，优先攻击重甲目标 |
| **迫击炮**（改装炮台） | 炮弹系 | 自动范围轰炸，固定冷却 |

### 弹药物流

- **产线**：自动生产子弹和炮弹，可切换优先级（均衡/子弹优先/炮弹优先）
- **搬运工**：AI 自动拾取弹药并装填到枪手/炮台的弹匣中
- **弹匣容量**：枪手 5 发，炮台 2 发

### 敌人类型

| 类型 | 特点 |
|------|------|
| 步兵 | 基础敌人 |
| 跑者 | 速度快、血量低 |
| 坦克 | 装甲目标，普通子弹减伤 52% |
| 破坏者 | 优先破坏产线 |
| 治疗者 | 周期性治愈附近盟友（第 3 关起出现） |
| Boss | 每关第 10 波，自带护盾（仅炮弹有效），血量低时进入狂暴阶段 |

### 升级系统

- **商店升级**：产线等级、枪手/炮台数量与强化、搬运工数量
- **波次强化（三选一）**：每波结束后从随机池中选择一项强化
- **共鸣系统**：强化带有标签（🔥火/🛡防/⚡速/💰财），集齐 3 个或 6 个同系标签触发共鸣效果

### 共鸣效果

| 系 | 3层 | 效果 | 6层 | 效果 |
|----|-----|------|-----|------|
| 🔥火 | 烈焰共鸣 | 所有伤害+8% | 焚天 | 燃烧弹持续+50% |
| 🛡防 | 钢铁壁垒 | 城墙上限+1 | 铜墙铁壁 | 阵地维修时间-30% |
| ⚡速 | 极速供应 | 传送带+10% | 闪电物流 | 搬运工速度+15% |
| 💰财 | 财源广进 | 基地收入+2 | 黄金时代 | 击杀奖励+10% |

## 文件结构

```
ammo-defense.html    主页面
ammo-defense/
  core.js            核心逻辑：状态管理、常量、波次生成、强化选项、共鸣系统
  systems.js         游戏系统：搬运工AI、敌人行为、战斗、弹道物理、事件
  render.js          渲染层：所有游戏元素的 Canvas 2D 绘制
  game.js            主循环：requestAnimationFrame 循环、用户输入
  background.js      静态背景：天空、废墟、地形、基地建筑
  styles.css         UI 样式：覆盖层、按钮、选择面板
```

---

## 技术栈

- 纯 HTML + CSS + JS，无框架依赖
- Canvas 2D 实时渲染
- Web Audio API 音效
- localStorage 存档（最高关卡记录）
